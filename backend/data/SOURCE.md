# Dataset provenance

The assignment dataset is a curated Bangalore area → pincode list with latitude/longitude
for map links.

Reference used during project preparation:
- Public Bangalore pincode map gist: https://gist.github.com/sugunagar/51badabd059bec390ef64d32164c5412
- India Post pincode directory: https://www.indiapost.gov.in/rti/pincodelist
- India Post locator: https://www.indiapost.gov.in/locate-postoffice
- Government Open Data pincode directory: https://www.data.gov.in/resource/all-india-pincode-directory-till-last-month

For production postal accuracy, periodically reconcile this seed dataset with the latest
Department of Posts / Government Open Data source.
